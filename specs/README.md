# specs/

One file per page. The file name decides which draft it controls:
`specs/faq.md` always edits the same FAQ draft, `specs/timeline.md` its own.

Get a spec three ways:
1. Copy a template: `skills/<skill>/spec_template.md` → `specs/<page>.md`.
2. Run `python navipress.py plan`; it writes DRAFT specs here from your
   knowledge folder. Fix every `[STUDENT: ...]` before building.
3. Adapt an example from `examples/`.

For Module 9.2, write (or heavily rewrite) the spec yourself and note in
your journal how much of it you wrote.
